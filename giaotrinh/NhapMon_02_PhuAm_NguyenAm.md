# Nhập môn 2 — Phụ âm đầu & vần ⏱ 40 phút

> Phần "gần giống tiếng Việt" chỉ là **mốc tạm** để bạn dễ hình dung. Phát âm chuẩn thì bạn phải **nghe** (Google Dịch hoặc Pleco).
> **Bật hơi** nghĩa là có luồng hơi mạnh bật ra. Bạn đặt tờ giấy trước miệng khi đọc: âm bật hơi sẽ làm tờ giấy rung.

## 1. Phụ âm đầu (21 âm)
| Nhóm | Âm | Gần giống tiếng Việt | Ví dụ |
|---|---|---|---|
| Môi | **b** | "p" không bật hơi | 爸 bà |
| | **p** | "p" **bật hơi** | 怕 pà |
| | **m**, **f** | m, ph | 妈 mā, 饭 fàn |
| Đầu lưỡi | **d** | "t" | 大 dà |
| | **t** | "th" | 他 tā |
| | **n**, **l** | n, l. Người Việt hay lẫn n/l, cần chú ý | 你 nǐ, 来 lái |
| Cuống lưỡi | **g** | "c/k" | 哥 gē |
| | **k** | "c" **bật hơi**, không đọc thành "kh" | 口 kǒu |
| | **h** | Gần "kh" nhưng nhẹ hơn | 好 hǎo |
| Mặt lưỡi | **j** | "ch" (chi) | 家 jiā |
| | **q** | "ch" **bật hơi** | 去 qù |
| | **x** | "x" | 谢 xiè |
| Uốn lưỡi | **zh** | "tr", đầu lưỡi cong lên | 中 zhōng |
| | **ch** | "tr" **bật hơi** | 吃 chī |
| | **sh** | "s", cũng uốn lưỡi | 是 shì |
| | **r** | Giữa "r" và "gi", rất nhẹ | 人 rén |
| Đầu lưỡi thẳng | **z** | "ch" đặt lưỡi sau răng, như "ts" | 再 zài |
| | **c** | "ts" **bật hơi** | 菜 cài |
| | **s** | "x" | 四 sì |

🔑 **Bốn cặp quan trọng nhất (không bật hơi / bật hơi):** b/p, d/t, g/k, j/q, zh/ch, z/c.

⚠️ **Chữ i đặc biệt:**
- Sau **z, c, s**: i đọc như "**ư**". Ví dụ: 四 sì ≈ "xư".
- Sau **zh, ch, sh, r**: i cũng đọc như "ư", nhưng uốn lưỡi. Ví dụ: 是 shì, 吃 chī.

## 3. Quy tắc viết pinyin
1. Sau **j, q, x, y**, chữ **ü** được viết thành **u**: 去 qù (thực ra là qü), 学 xué. Sau n và l thì vẫn giữ hai chấm: 女 nǚ, 绿 lǜ.
2. Khi không có phụ âm đầu:
   - i viết thành yi hoặc y: 一 yī.
   - u viết thành wu hoặc w: 我 wǒ.
   - ü viết thành yu: 鱼 yú.
3. Có ba vần viết rút gọn: iou → iu, uei → ui, uen → un.
