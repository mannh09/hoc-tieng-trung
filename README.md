# 中 Học tiếng Trung HSK1

Trang web tự học tiếng Trung sơ cấp (HSK1) bằng tiếng Việt: có pinyin, âm Hán Việt, hội thoại, bài tập và phát âm.

**👉 Mở trang học:** xem link ở mục *About* bên phải (GitHub Pages), hoặc tải file [`docs/index.html`](docs/index.html) về rồi mở bằng trình duyệt, dùng được cả khi không có mạng.

## Có gì bên trong
- **Bài học:** 3 bài nhập môn (thanh điệu, phụ âm và vần, chữ Hán) + 10 bài HSK1 (chào hỏi, số đếm, gia đình, ăn uống, mua sắm, hỏi đường…)
- **Từ vựng:** tra cứu, lọc theo bài, đánh dấu từ đã thuộc hoặc chưa thuộc
- **Thẻ từ (flashcard)** và **Trắc nghiệm** để ôn
- **Bấm vào chữ Hán để nghe phát âm.** Nên dùng Microsoft Edge hoặc Chrome; điện thoại cần có giọng đọc tiếng Trung.
- Tiến độ được lưu ngay trên trình duyệt của bạn, không cần tài khoản

## Chạy / sửa code
```bash
npm install
npm run dev      # chạy thử
npm run build    # build ra docs/index.html
```
Nội dung bài học nằm trong thư mục [`giaotrinh/`](giaotrinh), từ vựng trong `src/vocab.js`.
